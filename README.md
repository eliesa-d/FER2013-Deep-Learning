# FER2013 Deep Learning

This repository contains my individual deep learning assignment.

The goal of the project is to classify facial expressions from grayscale images using Convolutional Neural Networks (CNN).

## Files

- `FER2013_deep_learning_inlamning.ipynb` – notebook containing code, training, evaluation, model comparison and analysis.
- `best_fer2013_model.keras` – saved trained model.

## Dataset

The project uses the FER-2013 dataset with seven facial expression classes:

- angry
- disgust
- fear
- happy
- neutral
- sad
- surprise

## Models

Two CNN models were trained and compared.  
The second model included an additional convolutional layer and dropout to reduce overfitting and improve generalization.
